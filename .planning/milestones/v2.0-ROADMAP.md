# Milestone v2.0: Enhanced Orchestration

**Status:** SHIPPED 2026-10-15
**Phases:** 5-8
**Total Plans:** 8 plans (19 plan summaries)

## Overview

Hardened the orchestration extension system with async support, telemetry, PID resilience, and real-time driver visibility. Built on the v1.0 hook porting foundation.

## Phases

### Phase 5: PID Resilience

**Goal:** Upgrade the lane driver lock schema to include process identity (start time, boot ID, nonce) so PID reuse cannot cause false liveness or stale-lock adoption.
**Depends on:** Nothing (foundation for phases 6-8)
**Plans:** 2 plans (A: lock schema v2 types + parser, B: integrate into lane-driver-manager)

- [x] 05-A: Lock schema v2 types, parser, and status derivation
- [x] 05-B: Integrate lock schema v2 into lane-driver-manager and block-manual-integrate

### Phase 6: Lane Driver Status UI

**Goal:** Expose lane driver daemon state through a read-only API route and render a real-time status badge in the task panel, with single-flight polling and visibility gating.
**Depends on:** Phase 5 (lock schema v2 provides the snapshot the API reads)
**Plans:** 2 plans (A: API route + polling engine, B: badge component + TaskPanel integration)

- [x] 06-A: API Route + Polling Engine (17 tests)
- [x] 06-B: Badge Component + TaskPanel Integration (11 tests)

### Phase 7: Block Rule Telemetry

**Goal:** Instrument the block rule evaluation pipeline with per-session timing and block counts, exposed through atomic snapshots.
**Depends on:** Phase 5 (state-home for snapshot paths), Phase 6 (pattern for atomic file reads)
**Plans:** 2 plans (A: TelemetryCollector + instrumented evaluation, B: atomic snapshots + extension wiring)

- [x] 07-A: TelemetryCollector + Instrumented Evaluation (10 tests)
- [x] 07-B: Atomic Snapshots + Extension Wiring (7 tests)

### Phase 8: Async Block Rules

**Goal:** Add an async evaluation path using the gather-then-decide pattern — prefetch git facts asynchronously, then run existing sync rules over the frozen context.
**Depends on:** Phase 7 (telemetry baseline), Phase 5 (state-home)
**Plans:** 2 plans (A: async git queries + thenable safety net, B: evaluateBlockRulesAsync + extension wiring)

- [x] 08-A: Async Git Query + Thenable Safety Net (8 tests)
- [x] 08-B: evaluateBlockRulesAsync + Extension Wiring (8 tests)

## Key Accomplishments

1. **Lock Schema v2** — PID resilience with process identity verification (proc_start, boot_id, nonce)
2. **Lane Driver Status Badge** — Real-time daemon status in task panel with 5-state discriminated union, single-flight polling, visibility gating
3. **Block Rule Telemetry** — Per-session timing and block counts with atomic snapshots, debounced writes, telemetry-isolated verdicts
4. **Async Block Rules** — Gather-then-decide pattern with prefetched git facts, per-rule timeout policy, thenable safety net in sync path
5. **136 new tests** — Full coverage across all 4 phases with TDD methodology
